# Asset manifest

One row per model, added in the same pull request as the model. `path` is
relative to `packages/assets/src/`. Leave `deviation and reason` empty unless
the model breaks a wishlist rule on purpose (for example an existing creature
kept at 5 cm per unit, or a building over the cube budget).

| id | path | cube count | texture size | deviation and reason |
|---|---|---|---|---|
